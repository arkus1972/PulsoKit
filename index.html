PulsoKit

Editor for the Roland TD-17 electronic drum module. Free, for macOS.

  • Edit every kit parameter over MIDI, straight from the module
  • Hear your changes before writing them permanently
  • Open, edit and save .TD0 kit files
  • Back up all 100 kits and restore them field by field
  • Read the trigger settings of all ten inputs
Download for macOS

macOS 14 or newer · Apple Silicon and Intel · TD-17 connected over USB

First launch

macOS will block it, because the app is not notarised with Apple. Open System Settings → Privacy & Security, scroll to the bottom and click Open anyway. Once is enough.

If you see “the app is damaged”, the download was incomplete — just download it again. Please don’t run any “repair” commands in Terminal.

Verify your download

Only ever download PulsoKit from its releases page. To prove a file really came from there:

gh attestation verify PulsoKit.zip --repo arkus1972/PulsoKit

Before you start

PulsoKit writes to your module’s memory. Back up your kits first — the Backup tab does it in one click. This is free software with no warranty; you use it at your own risk.
